# project/research — скрипти й сирі дані досліджень

Тексти звітів переїхали в [`../../docs/research/`](../../docs/research/) (індекс — там у `README.md`).
Тут лишилось те, на що посилаються звіти, код і конфіги:

- `scripts/` — одноразові заміри (`capture_frame.py`, `measure_swipes.py`).
- `early_spawn/scripts/` — аналіз анімації спавну (до `docs/research/early_spawn_detection.md`).
- `hazard_k5/` — скрипти й `res_*.jsonl` експерименту «k=5 резервуарів» (ризик смерті; запис у `docs/experiment-log.md`).
- `experiments/<run-id>/` — самодостатні підпапки результатів харнесу (`docs/experiments.md`).
- `live-matches/` — телеметрія всіх живих партій (`results.jsonl`, `aggregates.json`).
